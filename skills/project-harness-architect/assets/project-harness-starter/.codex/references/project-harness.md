# Project Harness map

This file is a navigation layer, not a replacement for project truth. Record the accepted harness plan path, authoritative documents, decision paths, active Spec paths, local skill inventory, validation entry points, and any domain-specific contract that supersedes the generic harness.

Runtime defaults live in `.codex/references/runtime-policy.json`. Resolved historical runtime lives in each `SPEC.execution.json`. Temporary thread/run state lives under `.codex/runtime/` and is not durable truth.
